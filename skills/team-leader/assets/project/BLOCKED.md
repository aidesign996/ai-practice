# Unresolved or Stopped Topics

Keep only current unresolved or explicitly stopped topics here. Link the current goal from [PROGRESS.md](PROGRESS.md). An empty template does not establish that all work is unblocked.

For an actual issue, record enough to recover:
- Affected requirement, action, or goal and its current limitation.
- Evidence and attempted paths; whether necessary test preconditions existed.
- Product / environment / test defect / unknown classification with its basis.
- Completed work, still-unverified outcomes, and independent work that can continue.
- Minimum missing input or capability; a supported next option if available.
- Any explicit stop or retry limit, its source, and conditions for resuming.

Do not infer product failure from a failed test precondition or completion from a written report. An explicit owner stop remains in force within its scope; renaming work does not bypass it. Archive resolved history through existing records rather than duplicating current state.
