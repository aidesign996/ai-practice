## 阅读方式

每份分享将尽量说明：

1. **解决什么问题**：适用场景和使用范围。
2. **需要准备什么**：工具、材料与必要条件。
3. **具体怎么做**：操作步骤和示例。
4. **最后得到什么**：结果展示、已验证的效果与已知限制。
