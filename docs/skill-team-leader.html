Team Leader

Give your AI project a team lead to coordinate the team and keep checking progress against your goal.

Version0.5.23 · 2026-09-10
Primary environmentCodex · Astra
LicenseMIT

1. Install the latest formal release

In a supported AI tool with access to your project, you can say:

Read https://github.com/aidesign996/team-leader, check the latest formal release at https://github.com/aidesign996/team-leader/releases/latest, and install its complete Team Leader Skill. Tell me the version actually installed.

2. Hand over the project in one sentence

After installation, select Team Leader or mention $team-leader in your project conversation, then say:

Please take responsibility for this and keep it moving. Retain useful experience as we go; when something similar comes up, look it up and consider how to use it.

Already installed? Update and continue

A new release does not automatically update your local Skill. Preserve project records and custom changes, then compare versions.

Check Team Leader’s latest formal release. Back up the old Skill and custom changes, then update the complete package. Preserve project goals, records, and unfinished tasks; check the installed version, have the existing lead adopt relevant changes, and continue the original work.

What happens next

The lead first recovers goals, existing results, and unfinished work. It reuses an appropriate existing professional owner; cross-project work needs communication tools and data access. It should retrieve relevant experience, compare current conditions, and improve its approach from actual results. The user defines goals and effective requirements; old cases are adjustable reference material.

Scope and usage

Designed primarily around Astra in Codex. Explicit user choices of model and effort come first. When automatic allocation is authorized, the lead usually starts at high; specialist effort follows task complexity. Checks should match the risks to the result. Simple work can stay solo, and multi-role coordination may use substantial quota.

Release 0.5.23 passed package and file-context checks. Adoption by five project leads was checked, including two that required reminders. This is not evidence of long-term omission-free behavior. Sol has partial specialist-role experience, with no comparable all-Sol team evaluation or reliable overall time or quota saving.
