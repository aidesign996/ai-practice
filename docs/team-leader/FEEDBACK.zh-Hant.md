# 說說你的使用感受

[English](FEEDBACK.en.md) · 繁體中文 · [简体中文](FEEDBACK.md) · [返回 Team Leader 介紹](ARTICLE.zh-Hant.md)

歡迎使用 Team Leader，也歡迎提出疑問和建議。我會根據真實使用反饋繼續優化。幾句話就可以，不需要懂系統論，不需要先找到技術原因。

## 直接寫就好

直接在網頁文章下方留言即可，原來的反饋網頁也顯示同一組留言，不用按格式分欄。可以聊聊當時想做什麼、實際發生了什麼、怎樣會更好；知道多少就寫多少。覺得好用的地方，也歡迎分享。

例如：“我讓負責人繼續修改頁面，它只回覆了計劃，我又追問了一次。希望它能在已有授權內繼續做；確實需要我決定時，再說清卡在哪裡。”

版本、使用工具或一張脫敏截圖可以幫助理解，但不必為了提交反饋專門整理技術報告。歡迎用英文、繁體中文或簡體中文。

[在文章下方留言](article-preview.zh-hant.html#comments) · [在 GitHub 查看討論](https://github.com/aidesign996/ai-practice/discussions)

三種語言共用一個公開討論區，可以直接在文章內查看、留言和回覆。首次留言需要登錄 GitHub 並授權 giscus；點擊發布後，內容公開保存到 GitHub Discussions。請去掉私人和業務機密信息。沒有 GitHub 賬號時，可以先閱讀，註冊後再參與。

> 我當時在做……，希望……。實際發生了……，讓我……。如果能……會更好。（不知道改法也沒關係。）

## 我會怎樣使用這些反饋

我會和技能維護負責人整理反饋，先理解場景和原目標，再核對實際發生的事，區分當前項目的需要與值得推廣的方法改進。調整後回到原場景檢查，說明改變、驗證結果和限制；你和其他使用者都可以在同一條討論裡繼續補充。

每條建議都值得理解，但不一定需要新增通用規則或發佈一個新版本。反饋的價值在於幫助方法適應真實工作。
